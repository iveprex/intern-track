# InternTrack

**A focused CareerTech workspace for managing internship opportunities and application pipelines.**

InternTrack is a self-initiated product concept built around a simple problem: students often discover opportunities across many websites but have no single, structured place to manage the resulting pipeline.

## Product focus

The application combines opportunity discovery, application tracking and lightweight career analytics in one workspace.

### Key capabilities

- Opportunity database
- Search and multi-filter workflow
- Application pipeline
- Status progression
- Deadline monitoring
- Opportunity intake form
- Career analytics
- Skill-frequency analysis
- Work-mode analysis
- Clean, responsive dashboard

## Tech stack

- Python
- Streamlit
- Pandas

## Product thinking

The interface intentionally prioritizes the information a student needs when making an application decision: **role, company, location, work mode, compensation, deadline, status and relevant skills**.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
